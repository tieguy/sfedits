# Fonts

Noto Sans (latin subsets) from [Fontsource](https://fontsource.org/fonts/noto-sans),
licensed under the [SIL Open Font License 1.1](https://openfontlicense.org/).
Copyright the Noto Project Authors.

Used by `lib/diff-render-native.js` (satori) to render diff images without a
browser. CJK coverage is fetched at runtime and cached under `data/fonts/`.
